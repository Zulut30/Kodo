# Next.js

Перед работой прочитай package.json, lockfile и структуру маршрутов. Сохраняй выбранные проектом router, package manager и систему стилей. Границы server/client определяй по данным и взаимодействию; секреты остаются на сервере.

Для публичных страниц проверь метаданные, canonical и доступность основного контента в HTML. Проверяй штатную production-сборку и относящийся к задаче сценарий. Команды бери из проекта: наличие Next.js не означает наличие конкретных npm scripts.

Комплект устанавливает пайплайны функций, багов, сайтов и релизов, связанные роли и навыки, шаблоны GitHub и браузера. Пресет не создаёт приложение и не устанавливает зависимости Next.js.
