description: Фиксируй значимые архитектурные решения с контекстом, альтернативами и последствиями при планировании и документировании в Kodo.
---

Проверь существующие ADR и соглашения проекта. Для существенного выбора технологии, границы API или модели данных запиши контекст, выбранный вариант, альтернативы и последствия. Рутинное исправление не требует нового ADR. Свяжи решение с фактическим изменением и его проверкой; статус принятия должен соответствовать имеющимся полномочиям пользователя.

Шаблоны и оригинал wshobson/agents: [upstream](references/upstream/SKILL.md.original), [decision templates](references/upstream/references/decision-templates.md). Читай нужный шаблон; не навязывай новый каталог документации, если в проекте уже есть подходящий. Kodo продолжает порученную работу без повторного согласования штатных этапов.
