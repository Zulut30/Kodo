# GitHub MCP

Официальный GitHub MCP в Docker, режим чтения. Нужны установленный и запущенный Docker и GitHub PAT с доступом только к нужным репозиториям. Перед запуском клиента передай `GITHUB_PERSONAL_ACCESS_TOKEN` через окружение; токен не записывай в файлы toolkit. Docker получает имя переменной, её значение не попадает в аргументы.

Выбери шаблон и объедини его секцию с конфигурацией проекта: Codex — `.codex/config.toml`, Claude Code — `.mcp.json`, OpenCode — `opencode.json` или существующий `opencode.jsonc`. В Codex/OpenCode после настройки поменяй `enabled` на `true`. Для Claude Code шаблон станет активным после добавления в `.mcp.json` и принятия настроек клиентом. Перезапусти клиент, проверь список MCP и выполни чтение файла из разрешённого репозитория.

Toolkit только копирует шаблон в `.ai-toolkit/components/mcp/github/`; не меняет конфигурацию клиента и не запускает Docker. В шаблоне образ без фиксированного тега; перед использованием в воспроизводимой среде выбери версию или digest по документации сервера.

Источник: [github/github-mcp-server](https://github.com/github/github-mcp-server). Формат клиентов проверен по их официальной документации 2026-11-02; соединение с сервисом требует отдельной проверки.
