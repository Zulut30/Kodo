# Browser MCP

Официальный Playwright MCP с отдельным профилем в памяти (`--isolated`). Он не использует авторизацию основного браузера. Нужны Node.js/npm и поддерживаемый установленный браузер согласно документации Playwright MCP. При первом подключении npx скачает сервер.

Выбери шаблон и объедини его секцию с конфигурацией проекта: Codex — `.codex/config.toml`, Claude Code — `.mcp.json`, OpenCode — `opencode.json`/`opencode.jsonc`. В Codex/OpenCode включи сервер через `enabled = true`/`"enabled": true`. Для Claude Code добавление секции предлагает подключение серверу в клиенте. Перезапусти клиент и проверь открытие тестовой страницы.

Toolkit хранит шаблоны в `.ai-toolkit/components/mcp/browser/`, не устанавливает сервер и не запускает браузер. `@latest` здесь означает установку текущей версии при запуске; для воспроизводимого окружения замени его конкретной проверенной версией.

Источник: [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp). Сверено 2026-11-02; работа браузера проверяется отдельно от синтаксиса шаблона.
