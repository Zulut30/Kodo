# Browser MCP

Официальный Playwright MCP с отдельным профилем в памяти (`--isolated`) сохранён как `kodo_browser`. Дополнительно доступен опциональный `kodo_chrome_devtools` — Chrome DevTools MCP с точным pin `1.12.0` и временным изолированным профилем. Они не используют авторизацию основного браузера. Нужны Node.js 24/npm и поддерживаемый установленный браузер. При первом подключении npx скачает выбранный сервер; шаблоны не являются managed installation runtime.

Выбери шаблон и только нужную секцию сервера, затем объедини её с конфигурацией проекта: Codex — `.codex/config.toml`, Claude Code — `.mcp.json`, OpenCode — `opencode.json`/`opencode.jsonc`. В Codex/OpenCode оба сервера по умолчанию выключены: включи выбранный через `enabled = true`/`"enabled": true`. В Claude Code отдельного `enabled` в этом шаблоне нет: копирование серверной секции уже предлагает подключение клиенту; не копируй оба сервера без необходимости. Перезапусти клиент и проверь открытие собственной тестовой страницы.

Kodo хранит шаблоны в `.kodo/components/mcp/browser/`, не устанавливает сервер и не запускает браузер при копировании. Playwright `@latest` сохранён для совместимости; для воспроизводимого окружения замени его проверенным pin. Chrome закреплён на `1.12.0`: `--isolated --no-usage-statistics --no-performance-crux`, `NO_UPDATE_CHECKS=1` и `CHROME_DEVTOOLS_MCP_NO_UPDATE_CHECKS=1`. Ключи не нужны и не включены. Не заменяй изолированный профиль личным и не подключай чужой remote-debugging endpoint.

Источники: [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp), [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp). Флаги Chrome сверены с README управляемого пакета `1.12.0`, 2026-11-03. Синтаксически корректный шаблон не подтверждает установку, авторизацию или живое соединение. Runtime UI gate использует отдельный managed pin, официальный SDK `1.32.2` и принадлежащий координатору CDP; его квитанции описаны в `docs/VALIDATION.md` исходного checkout Kodo и не удостоверяют клиентские настройки этого шаблона.
