## Известные ограничения после этапа

- Брифы `next-wave` вызывают `kodo` по имени: если на PATH другая версия Kodo, чем у диспетчера, самопроверку нужно запускать тем же CLI (в пилоте глобальная 0.2.6 заменялась локальным `node cli/index.mjs`).
- Самопроверка `ci feedback` свежего проекта возвращает `blocked`, пока координатор не установит управляемый oxlint (`kodo tools install oxlint`); для `.css` нужен конфиг stylelint.
- Карта файлов контекста `bootstrap --prepare` заполняется установленными навыками (400 файлов, `completeFileMap: false`).
- Ремонт gate Run ограничен двумя раундами: на задаче со «спором» с ревьюером (сложный лексер) гейт блокируется — решение остаётся за человеком (`gates --retry-failed`, сужение контракта или новая задача).
- `released` в волновом режиме не поддерживается; Orca — тот же протокол, не проверялся.
