## Соответствие приёмке MVP

| Требование | Чем подтверждено |
| --- | --- |
| Обязательный текст переживает truncation | Манифест с сокращённой обязательной секцией не строится; сессия с task-context без контракта отклоняется; полное описание задачи доходит до исполнителя |
| Отрицательные проверки: injection, invalidation, secret | В манифесте нет текста prompt и секретов (тест с секретом в Engine); изменённый или пропавший evidence даёт `invalidated`, сдвиг head — `stale` |
| Доказанно локальная CSS-задача обходится без Gemini/Jev/research | На настоящем Engine вызовы провайдера: только план, исполнитель и ревью; `research.requests` равно 0 |
| Сомнение возвращает обычный маршрут | 34 случая сомнения в классификаторе; на Engine — путь вне стилей, слово-маркер и явный `standard`; план вне доказательства отзывает быстрый путь и восстанавливает бюджеты |
| High-risk задача не теряет проверки | Быстрый путь не отключает проверки, gates и ревью; слово-маркер и явный широкий режим его не допускают |
| Resume и параллельность не расширяют caps | Лимит сессий сохраняется в Run: `resume` и `--retry-failed` не запускают новую сессию; Project retry сохраняет прежние лимиты |
| Usage отсутствует → null | Не менялось: `tests/metrics.test.mjs` |

## Независимое ревью

Первая версия прошла read-only ревью отдельным агентом. Вердикт — FAIL: один blocker и один major. Все замечания исправлены.

| Замечание | Исправление |
| --- | --- |
| blocker: модульный тест манифеста строил путь в формате Windows и упал бы на Linux CI | Путь строится разделителем платформы |
| major: отказ по лимиту сессий или размеру контекста на исполнителе считался сбоем узла: запускались research и повторная маршрутизация, итоговый код был не `budget` | Коды `budget`, `context_budget`, `context_manifest_invalid` проходят насквозь, как `quota`; тест с лимитом в одну сессию |
| Классификатор не видел `.env`, имена не из ASCII, длинные и цифровые расширения, пути без расширения | Любое слово с `/` или точкой не в конце обязано быть путём стиля |
| Слова-маркеры не ловились внутри слов (`oauth`, `redeploy`), «платёж», «базы данных» | Основы ищутся как подстроки; формы исправлены |
| Некорректный файл плана отзывал быстрый путь и расширял запуск до отказа | Структурная проверка и запрет замены после интеграции выполняются до сверки |
| Квитанция быстрого пути содержала поля недоступной оценки | Поля убраны, добавлено `assessment: "not_requested"` |
| Отслеживаемая символическая ссылка на Windows выглядит обычным файлом | Проверяется режим записи индекса Git |
| Документ обещал больше, чем проверяет код (обязательные секции, head манифеста, «любой путь — сомнение») | Формулировки уточнены |

Второе ревью итоговой версии: **PASS**, blocker и major нет. Его мелкие замечания исправлены частично:

- классификатор не считает файлами числа с единицами и понимает типографские кавычки;
- планировщику быстрого пути называют разрешённые файлы, чтобы честный план не отзывал доказательство;
- добавлены тесты на символическую ссылку в индексе Git и на каталог с именем стиля;
- документы уточнены: `context_budget` упаковщика, значение `source: fast-path`.

Ревью дельты: **PASS**; его замечание исправлено: числом считается только значение без единицы или с единицей CSS. Автоматическое ревью Codex в PR указало, что слишком большой контракт узла в файле плана отзывал быстрый путь до отказа; размер контракта теперь проверяется до сверки.

Не исправлено: исчерпанный лимит сессий проверяется только в момент сессии, поэтому повтор заведомо обречённого запуска заново выполняет подготовку (записано в руководстве).

CI первого head этого этапа остановила обязательная security-проверка: Gitleaks принял два фикстурных значения в тестах за ключи API. Значения заменены; локальный `gitleaks dir` находок не даёт.

## Изменённое существующее поведение

- Задача, называющая только существующие файлы стилей, больше не вызывает оценку Jev. Один существующий тест (`tests/mode-engine.test.mjs`, выбор `quick` по оценке) проверял именно такой текст; в его задачу добавлено упоминание `README.md`, чтобы он по-прежнему проверял обычный маршрут.
- В `run.sessionAttempts[]` появились поля `manifest` и `manifestSha256`.
- Без ключа `budgets` лимитов нет.

## Что не сделано

- **Адаптеры T3 Code и Orca** (scopes ③ и ④ плана). В репозитории нет описания их официальных интерфейсов; задания с `host: t3|orca` по-прежнему получают `host_unavailable`.
- **Перенос TokenEconomizer** (scope ⑤). Подготовленного кода в репозитории нет.
- **Interface cards** модулей и выбор контекста по AST/графу зависимостей.
- **Лимиты на Project и Milestone**, learned routing моделей.
- **Ограниченный host/utility pilot** и любые измерения токенов. Экономия не измерялась и не заявляется.
- **Анализ Gemini и оценка Jev** перед этапом не выполнялись: в этой среде нет настроенного Kodo runtime с провайдерами.

## Ограничения

- Быстрый путь покрывает только стили и только задачи, называющие файлы явно.
- Список слов-маркеров не распознаёт риск, описанный другими словами.
- Все свидетельства этапа — offline: fake providers, настоящие Git и SQLite.
