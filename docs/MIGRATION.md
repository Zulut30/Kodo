# Переход на Kodo

Новые установки используют команду `kodo`, каталог `.kodo` и префикс ролей `kodo-`.

Предыдущая версия называлась AI Toolkit и использовала `.ai-toolkit` и `aitk-`. Эти имена нужны только для распознавания старой установки и проверки мигратора.

При переходе проверяются прежний lock и SHA-256 управляемых файлов. Файл с локальной правкой сохраняется; конфликт не обходится принудительной перезаписью. Наличие подходящего имени без записи владельца в lock не даёт права заменить файл.

Миграция переносит только учтённые компоненты и обновляет пути служебных данных. Настройки клиента, `AGENTS.md`, `CLAUDE.md` и пользовательские инструкции сохраняются. Если новая установка уже существует, её содержимое проверяется до записи; конфликт версий не считается успешной миграцией.

После перехода проверь `kodo doctor`, `kodo list` и обнаружение навыков клиентом. Проверка миграции не подтверждает авторизацию и полное выполнение пайплайна.
