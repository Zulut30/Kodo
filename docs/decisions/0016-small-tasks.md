# ADR-0016: небольшие задачи — код в быстром пути, локальный план и предел старта сессии

Статус: решение этапа 14. Поведение описывают [CONTEXT](../CONTEXT.md#быстрый-путь) и [RUNTIME](../RUNTIME.md), не этот ADR.

## Контекст

Небольшая задача затягивалась. Без ключа Jev автоматический выбор режима всегда давал `standard`, а `standard` без ключа Gemini останавливался ошибкой `auth` анализа. Быстрый путь ADR-0010 принимал только стили, считал селектор `.button` путём, а «обнови/удали» — маркером риска. Даже доказанно маленькая правка тратила три нативные сессии (план, код, ревью). У сессии был только общий предел 30 мин: в старом пилоте маленькая задача шла 31 мин, из них около 29 мин до первого события клиента. Вход по подписке проверялся перед каждой сессией.

## Решение и альтернативы

| Выбор | Альтернатива и причина отказа | Последствие |
| --- | --- | --- |
| Без ключа Gemini автоматически выбранный режим продолжает с локальным анализом и записью `analysisFallback: "auth"` | Другой модельный API для анализа: запрещён границей ключей; блокировать как раньше: пользователь не получает работу | Явный `--mode standard|deep` по-прежнему требует Gemini |
| Быстрый путь `small_local` для 1–3 явно названных небольших отслеживаемых исходников | Решать по модели или по ключевым словам: это и есть вызов или ненадёжная эвристика, от которых уходим | Покрытие шире, доказательство по-прежнему локальное и детерминированное |
| Список расширений — JS/TS, Vue/Svelte, HTML и стили | Любые текстовые файлы: конфигурация, манифесты, shell, SQL и CI меняют зависимости, данные и окружение | Остальные файлы идут обычным маршрутом |
| Область записи — только однозначно названные цели правки, для обоих видов; тест пишется, только если он назван | Маски тестов (пропускали `tsconfig.test.json`, `tests/package.json`, helpers) и выведенные пути тестов (симлинки производных путей, контракт узла больше 12 000 байт) | Один список `run.fastPath.writePaths` равен названным файлам; регрессионный тест для неназванного файла идёт обычным маршрутом |
| Любая неоднозначность — сомнение, а не догадка: исключение или отрицание, незнакомый способ запуска, несколько слов в обратных кавычках, создание или удаление названного файла (одна токенизация, кавычки не мешают) | Наращивать эвристику распознавания команд и ограничений: каждая новая форма текста давала новый способ расширить права записи | Быстрый путь уже, зато каждое его решение объяснимо; имена после известного интерпретатора и `npm run` остаются аргументами |
| Селектор — только слово с ведущей точкой рядом со стилями, не файл, не dot-файл, не имя конфигурации и не секрет | Любое слово с точкой без `/`: `Node.js`, `app.properties`, `v1.2` перестали бы быть сомнением; селектор рядом с кодом прятал бы запрошенный файл | `.button` не отменяет быстрый путь стилей |
| Имя файла — одна обычная запись индекса, при `core.ignorecase` каноническое имя из индекса, файл внутри рабочего дерева на том же месте | Доверять пути из текста: регистр, каталог с тем же именем или связанный каталог подменили бы цель | `path_ambiguous`, `path_not_file`, `path_outside` — сомнение |
| Перед любой фиксацией изменений исполнителя — одна точная проверка тем же списком; удаление или замена названного файла — отказ | Проверять только завершение узла; `ownsPath` по префиксу каталога | Восстановление правок, интеграция и сверка с базой не проводят чужие файлы |
| Сохранённое доказательство `small_local` промежуточного формата отзывается до исполнителя | Мигрировать его список | Обычное перепланирование (`proof_outdated`); после начала работы — остановка `fast_path_outdated` |
| План доказанного быстрого пути строится локально, без сессии планировщика | Сессия планировщика с ограничением scope: лишняя сессия и минуты на однозначный план | Две нативные сессии: исполнитель и свежее независимое ревью |
| Предел старта `startupTimeoutMs` (120 с, не больше 600 с) с одним автоматическим повтором только при отсутствии событий | Предел простоя на всю сессию: длинные легитимные шаги без вывода прерывались бы | Зависший старт стоит не больше двух пределов; ошибка `unavailable` не тратит ремонт узла |
| Каждый нативный старт, включая повтор, проходит `budgets.sessions` и получает свою запись | Повтор внутри одной записи: лимит 2 допускал бы 3 старта | Отказ лимита останавливает запуск с `budget` до старта повтора |
| Попытка завершается только после подтверждённой остановки дерева или группы (остановка принадлежащих процессов из доставки); неподтверждённая — `process_teardown`, без повтора и ремонта | Завершать попытку по сигналу остановки: повтор стартовал бы рядом с выжившими потомками | Остановка на Windows дольше (PowerShell); сбежавший из дерева процесс не блокирует сессию дольше ~3 с, но может пережить её |
| Проверка входа — один кэш на загруженный Run, общий для обнаружения моделей и сессий | Глобальный кэш процесса: состояние переживало бы запуски и выход из подписки | Новый `run`/`resume` проверяет вход заново; неудачная проверка не запоминается |

## Границы

- Слова-маркеры риска остаются страховкой, а не доказательством безопасности; область записи узла, проверки и ревью не меняются.
- Повтор старта не различает зависший клиент и медленную сеть: оба получают ровно один повтор.
- Распознавание известных команд — узкий список (интерпретаторы, `npm`/`pnpm`/`yarn`); имя после незнакомой команды без опций и без глагола запуска считается целью и проверяется как файл.
- Клиент в собственной группе процессов на POSIX не получает SIGINT терминала напрямую: отмену передаёт Kodo; при аварийном завершении самого Kodo (SIGKILL) клиент может остаться.
- `firstEventMs` измеряет время до первого события клиента, а не задержку модели.

## Что отложено

Предел простоя после первого события, быстрый путь для других языков и для документации, локальный план для `--prepare`.
